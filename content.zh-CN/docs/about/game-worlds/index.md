# 游戏世界

登录帐户后，面板中会显示各种游戏世界供您选择。您可以加入的游戏世界数量没有限制，所以请随意尝试。但请注意，每个活跃的游戏世界都会从您的账户中扣除[积分]({{< relref "docs/about/payment/index" >}})。

您可以在[我们的网站](https://www.airlinesim.aero/worlds)上找到所有当前可用的游戏世界列表，包括它们各自的配置。

## 短期游戏世界

顾名思义，短期游戏世界有运行时间限制，通常持续约8-10个月，然后重启。

{{% hint info %}}
**信息**  
您在短期游戏世界的第一个控股公司每天消耗4个点数，每个额外控股公司每天消耗2个点数。
{{% /hint %}}

## 长期游戏世界

相对地，长期游戏世界持续运行，没有具体的结束日期。

{{% hint info %}}
**信息**  
您在长期游戏世界的第一个控股公司每天消耗6个点数，每个额外控股公司每天消耗4个点数。
{{% /hint %}}

## 中期游戏世界

这种游戏世界——在持续时间和成本上——是短期和长期世界的混合体。

{{% hint info %}}
**信息**  
您在中期游戏世界的第一个控股公司每天消耗5个点数。
{{% /hint %}}

## 专属游戏世界

专属游戏世界是允许进行个性化配置的私人游戏世界。您可以在我们[关于此主题的专门章节]({{< relref "docs/advanced/exclusive-game-worlds/intro/index" >}})中阅读更多相关内容。
