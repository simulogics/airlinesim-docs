# 付费模式

AirlineSim采用一种以公平、透明和易用为导向的付费模式。

本文涵盖了您需要了解的关于点数、点数消耗、价格、支付方式和游戏高级功能所需的所有信息。如果您对支付过程有任何疑问，请参阅我们的[支付常见问题解答]({{< relref "docs/faqs/payments.md" >}})。

## 动机

AirlineSim是一款非常小众的游戏（=活跃玩家相对少）。它也是一款严肃的商业模拟游戏，其服务器运行着复杂的模拟模型，这些模型非常消耗资源（=运营成本高）。

考虑到这两点，我们的付费模式需要满足某些要求。

1. 它必须能够覆盖相当高的每个活跃玩家成本。
2. 它必须足够灵活，以适应不同的使用强度，例如每个玩家的活跃控股公司数量不同，或长期运行的游戏世界。
3. 除了第一次购买时的"反作弊解锁"（详情见后文）之外，现实世界的金钱不得提供任何游戏内优势。
4. 尽管玩家群体相对较小，但是它必须产生足够的收入。
5. 它仍然需要允许哪些无法或不想花钱的玩家免费游玩。
6. 它必须尽可能对玩家公平，因为我们重视这一点。

这些要求排除了大多数常见的付费模式：

- **一次性购买**不足以支付持续的服务器成本。
- 强制性的**按期订阅**可能使玩家在停止游玩后继续付费，这种方式不够灵活，并且会导致更高的技术和管理复杂性。
- **广告模式**则"呃呃"，并且由于玩家数量较少，可能无法产生足够的收入来支付我们的开销。
- 大多数**免费游戏（Free-2-Play）**模式都被排除在外，因为它们要么依赖**付费优势（Pay-2-Win）**机制（这对于AirlineSim这样严肃的模拟游戏来说是不可接受的），要么依赖于通过毫无意义的装饰品**剥削少数玩家**，这既不公平，考虑到AirlineSim的规模也行不通。

因此，我们实施了一个基于积分的系统，多年来一直运行良好。

## 积分制：我们的付费模式概述

我们的付费模式围绕着**积分**。注册AirlineSim后，您的账户将获得**60个免费积分**。

在大多数游戏世界中，您创建的每个[控股公司]({{< relref "docs/advanced/setup/holdings-vs-subsidiaries" >}})都会被收取少量点数。具体数额取决于游戏世界的持续时间。但考虑到初始赠送的免费点数，以及短期游戏世界每天4点数的典型消费，您可以免费试玩此类游戏世界长达15天。

一旦点数用完，您需要为账户充值才能继续游戏。因此，点数系统是一种预付费模式，因此完全灵活。购买点数不构成定期订阅。您可以随时购买点数。如果您决定不再游玩，只需让您的点数用完即可。

差不多就是这样了！有一个注意事项：免费账户（即从未完成过支付的账户）和高级帐户（即在某个时间点至少完成过一次支付的账户）之间存在差异。我们将在下文讨论这一点。

## 点数消耗与用尽

一旦您创建了一个控股公司，您的账户每天都会被扣除点数。在您可以创建多个控股公司的游戏世界中，每个额外的控股公司享受一定的点数折扣。

目前，典型费用如下：
* 短期世界：4点/天（每个额外控股公司2点）
* 中期世界：5点/天（每个额外控股公司3点）
* 长期世界：6点/天（每个额外控股公司4点）

如果您的点数用完，您账户下的控股公司和其他公司将被锁定，直到您充值。在此期间，点数仍将按正常的每日费率扣除，这意味着已经为负的余额也会进一步降低。这样做的目的是防止公司通过放弃账户并在几周后返回游戏，以此避免为其增长和在此期间占用的游戏内资源付费，从而获得不公平的优势。

{{% hint info %}}
**示例**  
如果一个账户在一个短期游戏世界中拥有一家控股公司，并且点数用完，那么5天后其余额将为-20点。必须支付这些费用才能恢复游戏访问权限。
{{% /hint %}}

如果一个账户的点数连续28天以上为负，该账户的**所有持股和航空公司**将在**所有游戏世界**中被删除，从而释放被占用的游戏内资源，例如占用的航班时刻和飞机，否则这些资源将无法供其他玩家使用。AirlineSim账户本身将保持可用，其点数余额将自动充值至最初的60点，从而将您的账户重置为初始状态。如果之前拥有高级会员资格，重置后仍将保留。

请记住，28天的宽限期适用于之前购买过点数的付费账户。对于试用账户，在点数用完后7天，航空公司将被删除。

{{% hint danger %}}
**危险!**  
请注意，因点数余额为负而导致的自动删除会影响账户在**所有**游戏世界（**包括免费游戏世界**）中的资产！
{{% /hint %}}

## 免费游玩：免费账户与付费账户

AirlineSim提供免费的短期游戏世界，这意味着在那里玩游戏无需支付任何费用。因此，您可以无限期地免费玩AirlineSim。

但也有一些限制存在：除非您至少完成了一次付款，否则您的账户将保持**免费或试用状态**。这意味着即使在免费游戏世界中玩游戏，游戏的一些功能也无法使用。

这些功能中的大多数都涉及多个账户之间的直接互动，而要求至少完成一次付款是一种非常有效的反作弊机制。此类功能包括：

* 创建多个控股公司
* 一家控股公司旗下的多家航空公司
* 提供或接受私人合同（例如飞机租赁或联运）
* 出售飞机
* 竞标非官方飞机报价
* 裁员（因为被解雇的员工会进入一个可供其他玩家使用的员工池）
* 证券交易功能（[首次公开募股]({{< relref "docs/advanced/finances/initial-public-offerings/index" >}})和股票交易）
* 玩家拥有的建筑

有几个功能因历史原因而受到限制。在这一代的AirlineSim于2007年左右推出时，这些功能给我们的服务器带来了更高的负载，因此被限制为仅高级帐户可用：

* [在线预订系统（ORS）]({{< relref "docs/advanced/bookings/online-reservation-system/index" >}})
* 集成航班运行控制

一旦这些功能完成其现代化实现，这些限制可能会解除。

## 定价

AirlineSim提供分级定价模式，包含不同价格的套餐，让您可以根据不同情况选择合适的点数：如果您只是想小试牛刀，或以低廉的价格获取高级会员资格，可以购买小额套餐；如果您打算长期游玩，可以购买大额套餐，享受批量折扣。

截止本文撰写之时，最小的50点数套餐售价为2.49欧元。因此，在此套餐价格水平上，一个每天消耗4点数的简单账户每月费用约为6欧元。而更受欢迎的500点数套餐售价为19.10欧元，该价格已降至每月约4.60欧元。

您可以在[账户管理页面](https://accounts.airlinesim.aero/account/credits)找到所有价格和相应批量折扣的完整最新列表。

## 支付方式与结账

要购买AirlineSim点数，只需登录您的账户并点击"购买点数"。在这里您可以选择所需的套餐大小，选择性地输入优惠券代码（目前仅限Steam以外的平台），然后选择您的支付方式。

{{% hint info %}}
**信息**  
目前，结账时可使用以下支付方式：信用卡和借记卡（Visa, MasterCard, American Express）、Paypal、paysafecard、在线银行转账和预付款。如果通过Steam游玩，则可以使用Steam提供的所有支付方式。
{{% /hint %}}

请注意：实际可用的支付方式可能取决于您付款时所在的国家和所选的套餐大小。

您的付款处理完成后，点数将添加到您的账户中。
