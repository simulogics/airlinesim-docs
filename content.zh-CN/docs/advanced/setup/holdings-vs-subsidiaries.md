# 控股公司与子公司

当你以新公司起步时，你会在你选择的国家创建一个控股公司，并获得 1000 万 AS$ 的资本（请注意，起始资本金额可能因游戏世界而异）。利用这笔资金，你可以购买飞机并成为一家营运企业。不过，你也可以使用你的资金（或其部分）来创建一家子公司。在那种情况下，你的子公司可以租赁或购买飞机并经营你的航空公司。那么它们有什么区别呢？

你的控股公司是你所有商业活动的母投资公司，并且会限制你的航权（取决于其成立的国家）。它将永远属于你，因此你不能出售它或出售其股份。

如果你创建子公司，你可以公开募股并在股票市场上出售你的航空公司股份。通过你的 [IPO（首次公开募股）] 你可以吸引新资金，并在之后仍然拥有该子公司 80%的所有权。

由于上市能带来资本注入，使你能更快扩张，因此会给公司带来提振。不过，你必须每周向股东支付相当于利润 15%的股息（如果不上市，子公司仍归你所有且不支付股息）。

由于你的控股公司拥有 80%的股份，80%的股息归控股公司所有。你可以在股票可售时回购股份，或者你的控股公司可以将其 80%的股份中更多部分出售给公众。控股公司与子公司之间不可转移资金，即便你持有子公司 100%的股份也不例外。

{{% hint info %}}
**信息**  
如果你购买了另一家航空公司的股份，将可以获得关于其运营的详细信息，因此从主要竞争对手那里购买少量股份可能会很有趣。
{{% /hint %}}

除了首次公开募股外，如果你想拥有超过三种维护飞机系列，或想为洲际航班和货运部门设立专门的企业，创建子公司也可能很有意义。如果你的控股公司购买飞机并将其租赁给子公司，你甚至可以将部分利润转移到控股公司。
